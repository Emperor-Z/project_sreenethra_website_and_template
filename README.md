# Sreenethra Eye Care — Clinical Website

Clinical website for Sreenethra Eye Care, a multi-branch ophthalmology practice in Trivandrum, India. Built during a research internship focused on clinical tooling, patient-facing UX, and game-based amblyopia therapy.

## Project Snapshot

| Area | Details |
|---|---|
| Domain | Ophthalmology / healthcare UX |
| Role | Research intern; website implementation and clinical tooling support |
| Stack | HTML5, CSS3, TypeScript |
| Related work | Unity-based amblyopia therapy game with progressive exercises and clinician review workflows |

## What I Built

- Multi-page clinical website covering services, doctors, departments, scheduling, blogs, contact, and recruitment pages.
- Patient-facing layout designed for clarity across age groups and device sizes.
- Appointment and contact flows for a multi-branch ophthalmology practice.
- Supporting UX work connected to therapeutic game development and clinical workflow design.

## Game Technology Context

This website was developed alongside a Unity-based therapeutic game for amblyopia treatment. The game work focused on turning repetitive visual exercises into structured interactive tasks:

- Focus-shift exercises for visual attention and tracking
- Reflex and response-time tasks
- Progressive difficulty and session structure
- Performance logging for clinician review
- Visual stimulus design for therapy workflows

Clinical data, patient records, and proprietary deployment details are not included.
