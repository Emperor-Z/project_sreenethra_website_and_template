# Sreenethra Eye Care — Website

Clinical website for Sreenethra Eye Care, a multi-branch ophthalmology practice in Trivandrum, India. Built as part of a research internship focused on therapeutic game development and clinical tooling.

---

## Pages

| Page | Description |
|---|---|
| `index.html` / `Home.html` | Landing page with services overview |
| `Departments.html` | Department listing and specialisations |
| `Doctors.html` / `Doctor_Details.html` | Clinician profiles |
| `Schedule.html` | Appointment scheduling interface |
| `Services.html` | Full services catalogue |
| `Blogs.html` | Medical education articles |
| `Contact_us.html` | Contact and branch locations |
| `Career_Details.html` / `Join_us.html` | Recruitment pages |

---

## Tech Stack

- HTML5 · CSS3 · TypeScript
- Responsive layout (mobile-first)
- Designed with accessibility for patients across age groups

---

## Context

This website was developed alongside a therapeutic amblyopia treatment game (Unity) during a 6-month research internship at Sreenethra Eye Care. The internship also included working with ophthalmologists to validate game-based treatment protocols against conventional patch therapy.
