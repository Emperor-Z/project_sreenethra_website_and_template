## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A local web server (optional, for development)

### Installation

1. **Clone or download** the project files to your local machine
2. **Organize images**: Place all images in the appropriate folders within the `images/` directory
3. **Update assets**: Replace placeholder assets in the `assets/` folder with your actual logos and icons
4. **Customize content**: Update the HTML files with your specific content

### Development Setup

1. **Local Server** (Recommended):
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

2. **Open in Browser**: Navigate to `http://localhost:8000` to view the website

## 🎨 Customization Guide

### 1. Branding & Colors

**Primary Colors:**
- Main: `#0fccce` (Teal)
- Secondary: `#0db8b8` (Darker Teal)
- Text: `#333333` (Dark Gray)
- Background: `#ffffff` (White)

**Update colors in `css/styles.css`:**
```css
:root {
    --primary-color: #0fccce;
    --secondary-color: #0db8b8;
    --text-color: #333333;
    --background-color: #ffffff;
}
```

### 2. Content Updates

**Homepage (`Home_Clean.html`):**
- Update hero section text
- Modify service descriptions
- Replace team member information
- Update contact information

**Other Pages:**

- Maintain consistent structure across all pages

### 3. Images & Assets

**Required Images:**
- `assets/logo.png` - Main logo (recommended: 200x60px)
- `assets/favicon.png` - Website favicon (32x32px)
- `images/doctor-1.jpg` to `images/doctor-5.jpg` - Doctor photos
- `images/gallery-1.jpg` to `images/gallery-4.jpg` - Gallery images
- `images/blog-1.jpg` to `images/blog-3.jpg` - Blog post images

**Image Guidelines:**
- Use high-quality images (minimum 1200px width for hero images)
- Optimize images for web (use tools like TinyPNG)
- Maintain consistent aspect ratios
- Use descriptive alt text for accessibility
