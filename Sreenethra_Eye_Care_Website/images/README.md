## Image Guidelines

1. **Professional Quality**: All images should be high-quality, professional photographs
2. **Consistent Style**: Maintain consistent lighting and color tone across all images
3. **Optimization**: Compress images for web use while maintaining quality
4. **Alt Text**: All images have descriptive alt text for accessibility
5. **Copyright**: Ensure all images are properly licensed or owned

## Placeholder Images

Until actual images are provided, the website will display placeholder images. To replace them:

1. Add your images to the appropriate folders
2. Use the exact filenames listed above
3. Ensure proper sizing and optimization
4. Test the website to ensure all images load correctly

## Image Optimization Tips

- Use tools like TinyPNG or ImageOptim to compress images
- Maintain aspect ratios as specified
- Use descriptive filenames
- Consider using WebP format for better compression (with JPG fallbacks)
